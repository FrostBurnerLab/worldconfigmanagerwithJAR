# WorldConfig Manager 0.1.0 — kant-en-klare JAR

| Bestand | Gebruik |
|---|---|
| `worldconfigmanager-0.1.0.jar` | De mod. Zet hem in de map `mods/` (client en/of server). Dit bestand upload je naar Modrinth. |
| `worldconfigmanager-0.1.0-sources.jar` | Broncode-JAR (optioneel, niet nodig om te spelen). |
| `SHA256SUMS.txt` | Controlegetallen van beide bestanden. |

Vereist: Minecraft 26.3, Fabric Loader ≥ 0.20.1, Fabric API (getest met 0.165.2+26.3), Java 25.

Gebouwd met `./gradlew clean build` uit commit 4c211a3 van FrostBurnerLab/worldconfigmanager.
